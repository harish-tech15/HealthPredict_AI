# 🩺 HealthPredict AI

### AI-Powered Educational Diabetes Risk Prediction System

HealthPredict AI is an educational AI/ML application that demonstrates diabetes risk prediction using an Artificial Neural Network (ANN). It provides an interactive Streamlit dashboard where users can enter health measurements and explore model predictions.

> **Disclaimer:** This project is for educational purposes only. It is not a medical diagnostic tool and must not be used for medical decisions.

## ✨ Features

- 🔍 AI-based diabetes prediction demonstration
- 🧠 Artificial Neural Network (ANN)
- 📊 Interactive prediction dashboard
- 💬 Educational Health Assistant
- 📁 Prediction history
- 📥 Download prediction history as CSV
- 🌙 Modern dark-themed interface

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- Scikit-learn
- Pandas
- NumPy
- Streamlit
- Joblib

## 🧠 Machine Learning Workflow

1. Dataset loading
2. Data preprocessing
3. Missing/invalid value handling
4. Feature scaling using StandardScaler
5. Train-test splitting
6. ANN model training
7. Model evaluation
8. Streamlit deployment

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/HealthPredict-AI.git
cd HealthPredict-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## 📊 Dataset

This project uses the Pima Indians Diabetes Dataset for educational model development and experimentation.
